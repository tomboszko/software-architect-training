# Technical Documentation

This folder contains **original, publishable technical work** produced while studying software architecture.

- [Architecture decision records](adr/0000-template.md): structured explanations of engineering choices, alternatives and trade-offs.
- [Public showcase](showcase.md): links to independently demonstrated exercises, labs and projects.
- [Publication checklist](publication-checklist.md): safety review before publishing new material.

## Documentation principles

1. Explain the problem and relevant constraints before the chosen technology.
2. Show a diagram only if it makes responsibilities or relationships clearer.
3. Separate what is implemented and tested from what is merely planned.
4. Document alternatives and limitations without claiming a production guarantee.
5. Do not copy instructor materials, restricted exercises, third-party source code or confidential case-study data.

Private training schedules, learning assessments and personal notes are managed outside this public repository.
