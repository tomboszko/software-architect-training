# Projects

This area will host a small number of substantial, original projects demonstrating practical software architecture.

## Quality bar for each project

- Problem statement and users.
- Functional and non-functional requirements.
- Architecture diagram and important ADRs.
- Technology selection and trade-offs.
- Reproducible local setup.
- Tests, observed results and known limitations.
- Screenshots or demonstration only when authentic and safe to publish.
