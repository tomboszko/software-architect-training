# Exercises

Short, focused C# and .NET practice tasks will be stored here as the official training reaches each concept.

## Learning protocol

- **A — Fundamentals:** one new concept, minimal starter and visible test cases.
- **B — Application:** combine concepts, handle invalid inputs or edge cases.
- **C — Design:** implement a small component and explain testing and trade-offs.

The learning workflow is: problem → independent attempt → optional hint → test → explanation and review.

Each published exercise should explain:
1. Learning objective and relevant prerequisite.
2. My implementation (with clearly separated starter code if useful).
3. How to run it and what the tests demonstrate.
4. What I learned or would improve.

Only original or redistribution-authorized exercise statements and solutions belong in this public folder. The private learning tracker remains in TOMS-OS.
