# Technical Labs

Focused experiments will validate individual .NET and architecture concepts before combining them into a complete application.

Possible future areas, subject to the instructor's actual module sequence:
- ASP.NET Core endpoints and request processing;
- Entity Framework Core and Dapper;
- Dependency injection and design patterns;
- Automated testing and debugging;
- Docker containers and cloud deployment;
- Authentication, authorization, security and performance.

Each lab should include a minimal working example, setup instructions, expected and observed behavior, tests where relevant, and limitations.

These topics are a **proposed learning map**, not a claim that they have already been taught or implemented. No lab has been published yet.
